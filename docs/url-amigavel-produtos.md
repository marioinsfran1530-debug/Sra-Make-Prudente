# URLs amigáveis de produtos

Implementação em 2026-09-07.

- URLs públicas passam a usar nome + marca em formato slug.
- URLs legadas por ID continuam aceitas e redirecionam permanentemente para a URL amigável.
- Sitemap, canonical, cards, compartilhamento e dados estruturados passam a usar a URL amigável.
- O cadastro impede que dois produtos usem o mesmo nome e marca. Quando houver
  cor, modelo ou acabamento diferente, essa característica deve constar no nome.
- Endereços compartilhados antes da correção de produtos duplicados continuam
  aceitos e redirecionam para o primeiro item que já era exibido naquele link.

Exemplo:

`/produto/cmt60ncto000eilfu7x8jydyf`

→

`/produto/cilios-tufinho-30p-n-9-ao-14-new-show`
